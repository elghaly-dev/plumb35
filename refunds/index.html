Refunds

Card via Stripe

Back to the same card. Allow 5–10 business days.

Wallet transfer

Back to the address it came from, in the same asset, on the same network, within 3 business days. Network fees are deducted. Send from an address you control; we cannot refund an exchange deposit address.
